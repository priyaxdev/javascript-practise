# JavaScript Practice Projects 🚀

This repository contains mini projects built while learning JavaScript fundamentals. The projects focus on DOM manipulation, event handling, functions, conditional logic, and building interactive web applications.

---

## 📂 Projects Included

### 🧮 Calculator
A simple calculator that performs basic arithmetic operations.

**Features**
- Addition, subtraction, multiplication, and division
- Interactive button-based UI
- Clear functionality

**Concepts Used**
- DOM Manipulation
- Event Handling
- Functions
- Conditional Logic

---

### 🔢 Counter App
A counter application with interactive functionality.

**Features**
- Increment counter
- Decrement counter
- Reset functionality
- Dynamic background color changes

**Concepts Used**
- DOM Manipulation
- Event Listeners
- Variables and Functions

---

### ❌⭕ Tic-Tac-Toe
A two-player Tic-Tac-Toe game.

**Features**
- Winner detection
- Game reset functionality
- Interactive gameplay

**Concepts Used**
- Arrays
- Conditional Statements
- DOM Manipulation
- Event Handling

---

### ✅ To-Do App
A task management application.

**Features**
- Add tasks
- Delete tasks
- Mark tasks as completed
- Add tasks using the Enter key

**Concepts Used**
- DOM Manipulation
- Event Listeners
- Dynamic Element Creation
- Arrays and Objects

---

### 🌤️ Weather App
A weather application that displays weather information for searched cities.

**Features**
- Search weather by city
- Displays weather details dynamically
- Responsive interface

**Concepts Used**
- API Fetching
- Async JavaScript
- DOM Manipulation
- Event Handling
